# Нахождение корня методом простых итераций

## Поставленная задача:

> Напишите алгоритм решения трансцендентных уравнений методом простых итераций.

## Итог выполнения задания:
Была разработана программа на языке `Java`, которая использует метод простых итераций для нахождения приближённого корня трансцендентного уравнения.

Для решения была использована функция:

**`f(x) = ln(x) + x − 2`**

*В задании конкретное уравнение и начальные параметры не указаны. Уравнение выбрано из примеров в презентации, а параметры заданы для этой программы.*

В результате был получен приближённый корень **x ≈ 1,55714** за **5 итераций**.

***

### Заданные начальные параметры:

*Начальное приближение:* **x₀ = 1,5**

*Параметр метода:* **b = −0,5**

*Точность:* **ε = 0,0001**

*Максимальное количество итераций:* **100**

***

### Примерный алгоритм работы:
1. Задаются начальное приближение `x`, параметр `b`, точность `eps` и счётчик итераций `n = 0`.
2. Вычисляется значение функции `f(x)` и поправка `dx = b * f(x)`.
3. Находится новое приближение `x = x + dx`.
4. Счётчик `n` увеличивается на `1`, в консоль выводятся номер шага и новое значение `x`.
5. Если модуль поправки меньше заданной точности (`|dx| < eps`), выводятся приближённый корень и количество итераций, после чего вычисления завершаются.
6. Если условие точности не выполнено за `100` итераций, выводится сообщение об остановке и вычисления завершаются.
7. Если ни одно условие остановки не выполнено, повторяются шаги 2–6.
